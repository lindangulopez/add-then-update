The ten fields

CodeMeta termWhat it holds
nameThe software's name
authorThe people (or organisations) who wrote it; an ORCID where there is one
descriptionA short text on what it does
licenseThe licence, as its SPDX URL (e.g. https://spdx.org/licenses/MIT)
versionThe version of this release
identifierA persistent identifier for the software (e.g. a DOI, an ARK or a HAL identifier)
softwareRequirementsWhat it needs to run (language version, libraries)
operatingSystemThe systems it runs on
codeRepositoryWhere the source code is developed (URL)
referencePublicationThe article to cite with the software

Bold = the five core fields. A deposit sends the code and its metadata; a SWHID comes back. "Loaded" is not "checked". More: codemeta.github.io
